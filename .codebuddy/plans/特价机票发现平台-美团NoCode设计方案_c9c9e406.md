## 产品概述

基于美团 NoCode 平台，设计并搭建「特价机票发现平台」网页应用。该平台旨在解决用户在各大 OTA 和航司间寻找特价机票时面临的信息分散、规则复杂、难以及时发现高性价比航班等痛点问题。

## 核心功能

- **特价航线聚合展示**：按目的地、出发地、价格区间筛选特价机票信息，聚合多源数据呈现
- **智能价格趋势**：展示历史价格走势与未来价格预测，辅助用户判断最佳购票时机
- **降价提醒订阅**：用户设置关注航线和目标价格，系统推送降价通知（模拟数据）
- **航司活动日历**：各航司/OTA 促销活动时间线，帮助用户提前规划出行
- **机票比价卡片**：同航线不同平台价格对比，标注最低价和性价比推荐
- **个人收藏与管理**：保存关注的航线和搜索历史，快速回访

## 用户核心诉求

本任务的核心不是代码实现本身，而是**通过美团 NoCode 的 AI Coding 对话能力**，系统化地展现产品思维能力和 AI 辅助设计的高效工作流。

## 技术栈选择

- **开发平台**：美团 NoCode（Vibe Coding / 零代码 AI 编程平台）
- **交互模式**：自然语言多轮对话 + Visual Edit 可视化微调
- **输出形式**：可部署的 Web 网页应用（含前端界面与模拟数据）
- **部署方式**：NoCode 一键云端部署，生成公开访问链接

## 实施策略：分阶段结构化 Prompt 工程法

### 核心方法论：五步递进式对话框架

在 NoCode 中采用**「需求定义 -> 信息架构 -> 视觉风格 -> 页面生成 -> 迭代优化」**的五步递进式 Prompt 结构，而非一次性描述所有需求。这种方式最能体现产品思维的系统性和 AI 协作的层次感。

### 各阶段的 Prompt 设计要点

**第一阶段：产品定位与需求声明**

- 用结构化的 PRD 语言向 AI 描述产品定位、目标用户、核心痛点
- 明确功能优先级（P0/P1/P2），体现产品优先级思维
- 定义关键用户旅程（User Journey）

**第二阶段：信息架构与页面规划**

- 让 AI 先输出站点地图（Site Map）和页面清单
- 确认每个页面的核心功能和信息层级
- 体现信息架构设计的专业性

**第三阶段：视觉设计规范输入**

- 指定美学方向（如 Editorial/Magazine 编辑杂志风 或 Luxury/Refined 精致奢华风，契合航空旅行的品质感）
- 定义色彩系统（航空主题建议使用深蓝+金橙色作为主色调，避免禁用的紫色系）
- 指定字体系统（推荐 DM Serif Display + Source Sans Pro 组合或类似专业字体组合）
- 定义布局策略（非对称布局、卡片悬浮感、大图沉浸式头部）

**第四阶段：分页面逐步生成**

- 每次只让 AI 生成一个页面，确保质量可控
- 首先生成首页（Landing Page）建立第一印象
- 再逐一生成功能子页面
- 每个页面的 Prompt 包含具体区块说明

**第五阶段：迭代优化**

- 使用 Visual Edit 进行局部微调
- 通过追加指令优化细节
- 确保整体一致性

### 最大化体现 AI 思考能力的技巧

1. **Prompt 中包含设计决策的理由**（如"选择编辑杂志风格是因为..."），引导 AI 展示理解力
2. **要求 AI 在生成前先给出设计方案**（"请先用文字描述你的设计方案再开始编码"）
3. **使用对比式指令**（"给我两个版本的风格方案供选择"）
4. **追问设计逻辑**（"为什么这样布局？有没有更好的方式？"）
5. **要求 AI 做权衡决策**（"在美观和性能之间如何平衡？"）

### 最大化体现产品设计能力的技巧

1. **从用户故事出发**（"作为一个经常出差的商务人士，我希望..."）
2. **包含竞品参考**（"参考天际航行的简洁风格，但加入更多数据可视化元素"）
3. **明确数据模型**（即使用模拟数据，也要定义清晰的数据结构）
4. **考虑异常状态**（无数据时的空状态设计、加载态设计）
5. **注重交互细节**（hover 效果、过渡动画、响应式适配）

## 设计风格方向：Editorial/Magazine + Aviation Luxury

采用**编辑杂志风格融合航空奢华质感**的设计方向。灵感来自高端旅行杂志的排版美学与航空公司品牌视觉体系。

### 设计理念

- **头部区域**：采用全宽沉浸式 Hero 区域，使用高质量航空旅行背景图（飞机舷窗视角/机场跑道/云层之上），叠加半透明渐变遮罩和大标题文案，营造"即将启程"的氛围感
- **内容布局**：采用非对称网格布局，左侧为主内容区（占 7/12），右侧为辅助信息栏（占 4/12），打破传统的居中对称布局
- **卡片设计**：机票信息卡片采用悬浮阴影效果，带有微妙的上浮 hover 动画，卡片内包含航线缩略图、价格标签（醒目的大字号）、航司 Logo 位、折扣百分比角标
- **色彩氛围**：以深海蓝（#0A1628）为基底色，搭配琥珀金（#D4A853）作为强调色（呼应航空公司的金色贵宾感），辅以纯白（#FFFFFF）和浅灰（#F5F7FA）作为内容底色
- **数据可视化**：价格趋势使用平滑曲线图表，促销日历使用时间轴横向滚动组件

## 页面规划（4 个核心页面）

### 页面一：发现首页（Landing Page）

- **Hero 区块**：全宽沉浸式头部，包含产品 Slogan「让每一次飞行都不必为价格妥协」、搜索入口（出发地/目的地/日期三段式搜索框）、热门航线快捷标签
- **今日精选特价**：横向滚动的特价机票卡片轮播区，每张卡片显示航线、原价/现价、折扣力度、剩余时效倒计时
- **价格趋势洞察**：简化的价格走势迷你图表模块，展示 3-5 条热门航线的历史价格曲线
- **航司活动预告**：横向时间轴样式的近期促销活动预告条
- **底部 CTA**：「设置降价提醒」引导注册/订阅入口

### 页面二：航线搜索结果页

- **搜索条件栏**：顶部固定筛选条（出发城市、到达城市、日期范围、价格区间、航司偏好、中转偏好）
- **排序工具栏**：价格最低 / 航程最短 / 性价比最高 / 出发时间 切换排序
- **机票列表区**：每条结果包含：航司名称+Logo位 | 起降时间 | 直飞/中转标识 | 价格大字突出显示 | 「查看详情」按钮 | 收藏图标
- **侧边栏**：价格分布柱状图（帮助用户了解市场价格区间）、已应用的筛选标签汇总

### 页件三：价格追踪与提醒页

- **我的关注列表**：卡片式展示用户已订阅的航线追踪项，每项显示当前最低价 vs 目标价（进度条样式）、价格变化趋势箭头、最近一次降价幅度
- **添加追踪入口**：简洁的表单弹窗或内嵌表单（出发地、目的地、目标价位）
- **通知记录**：最近收到的降价提醒列表，带时间戳和操作按钮（立即查看/取消订阅）
- **空状态设计**：当没有追踪项时，提供引导性插画和「添加第一条追踪」CTA

### 页面四：活动日历与攻略页

- **活动时间轴**：垂直时间轴布局，展示各航司/OTA 的促销活动，每个节点包含：活动名称、参与航司、活动规则摘要、「设置提醒」按钮
- **省钱攻略区**：卡片式文章列表（如「机票最便宜的一周是哪几天」「红眼航班值不值得选」），每篇带封面缩略图和阅读时长
- **热门目的地 TOP 榜单**：按价格排序的热门目的地排行榜卡片组
