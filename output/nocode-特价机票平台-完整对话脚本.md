## 📝 对话 #1 — 开场白：产品PRD声明

**【直接复制以下内容发送】**

```
你好！我想用你创建一个「特价机票发现平台」的网页应用。在开始之前，让我先详细描述一下我的产品需求：

=== 产品基本信息 ===

【产品名称】SkyDeal / 特价机票发现平台
【产品Slogan】让每一次飞行都不必为价格妥协

【目标用户画像】
- 核心用户：25-35岁年轻白领、自由职业者、学生群体
- 用户特征：
  * 注重性价比，愿意花时间比价但不想装太多App
  * 有一定出行频率（每月1-3次或每年多次旅行）
  * 对价格敏感但对体验有基本要求（不是极致低价党）
  * 会使用飞猪/去哪儿/携程但觉得信息太杂乱

【核心痛点（用户故事）】
1. "我想去成都玩，但不知道哪天买票最便宜" → 需要价格趋势和最佳购票时机建议
2. "各大航司都在搞活动，但我总是错过" → 需要活动聚合和提醒功能  
3. "同一个航班在不同平台价格不一样，比价好累" → 需要跨平台价格对比
4. "看到便宜票不敢下手，怕后面还有更便宜的" → 需要价格预测和置信度提示

【产品定位】
类似「什么值得买」的机票版 —— 不是OTA订票平台（不涉及支付交易），而是专注于**信息聚合、智能推荐、价格监控**的内容型工具。

【竞品参考】
- 天际航线（简洁风格参考）
- 飞猪（信息密度参考）
- 各航司官网（促销信息来源模拟）

【核心功能优先级】
P0（必须有）：
✅ 特价航线聚合展示（卡片列表形式）
✅ 智能搜索筛选（出发地/目的地/日期/价格区间）
✅ 价格趋势可视化（迷你图表）
✅ 降价提醒订阅（模拟数据展示）

P1（应该有）：
✅ 航司活动日历时间轴
✅ 性价比评分系统
✅ 收藏和历史记录

P2（可以有）：
⭕ 省钱攻略文章区
⭕ 热门目的地排行榜

=== 我的请求 ===

请先理解以上需求，然后告诉我：
1. 你对这个产品的整体理解是什么？
2. 你建议的产品结构（页面规划）是怎样的？
3. 有没有我遗漏的重要功能点？

等我们达成共识后，再开始具体的页面设计。
```
